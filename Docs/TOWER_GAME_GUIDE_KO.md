# Tower Cleanup — 플레이 빌드 안내

기존 InkRogue Unity 프로젝트의 게임 시스템을 확장한 로컬 Windows 버전입니다. 신규 제작 아트는 적용하지 않았고 기존 스프라이트와 임시 도형을 사용합니다.

## 실행과 조작

`Builds/TowerCleanupSaves/TowerCleanup.exe`를 실행합니다. 실행 파일 옆의 `TowerCleanup_Data`, `UnityPlayer.dll`, `MonoBleedingEdge` 등 동봉 파일을 함께 유지하세요.

- WASD: 이동 / 마우스: 조준
- 마우스 왼쪽 버튼: 오른손 무기 / 오른쪽 버튼: 왼손 무기
- Shooter·MachineGun: 누르고 사격. 충전형 무기는 누른 뒤 놓아 사용합니다.
- Shift: 잉크 형태. 아군 잉크 위에서 잠수하면 잉크와 방어막을 회복합니다.
- Q / E: 오른손 / 왼손 무기 휠. 누르는 동안 게임이 0.1배로 느려지며 마우스로 선택하고 키를 놓아 장착합니다. 휠·커서는 정상 속도로 반응하고, 닫으면 이전 배속으로 돌아갑니다.
- Esc: 일시정지·재개. 일시정지 화면에서 보유 파워를 확인하거나 저장하고 메뉴로 돌아갑니다.

## 게임 진행

20층 모드는 5·10·15·20층에서 보스가 등장하며 20층 보스 처치로 승리합니다. 무한 모드는 10층마다 보스가 등장하고, 네 보스 패턴이 순환합니다. 일반 전투는 기존 섬멸·러시·방어 형태와 맵을 이용합니다.

각 층을 클리어하면 난이도별 최대 2/3/4개 파워 후보에서 정확히 하나를 선택하고, 다음 층의 맵·난이도 및 무기 구성을 선택합니다. 캠페인 마지막 보스 이후에는 결과 화면이 열립니다. 재시작은 처음 모드 선택 화면으로 돌아가며 파워와 동료 성장이 초기화됩니다.

## 저장과 이어하기

층 시작, 파워/경로 선택, 장비 적용과 정상 사망 등 확정 지점에서 자동 저장합니다. 메뉴의 이어하기에서 모드·층·목숨·저장 시각을 확인할 수 있습니다. 전투 중 Esc → 저장하고 메뉴로를 누르거나, 보상·경로 화면의 같은 버튼을 사용하세요.

이번 층의 전투 진행은 저장되지 않습니다. 이어하기는 이 층 시작 시점으로 돌아갑니다. 전투 중 종료나 크래시 때문에 추가 목숨을 차감하지 않습니다. 정상 사망으로 이미 차감한 목숨은 유지합니다. 파워·경로 선택 중이면 같은 후보와 단계로 돌아갑니다. 적용하지 않은 장비 초안은 버립니다.

활성 런이 있을 때 새 런을 시작하면 교체 확인이 나옵니다. 취소하면 저장을 유지하고, 확인하면 이전 런을 중단 기록으로 남깁니다. 지난 런 기록에서 승리·패배·중단 결과와 날짜, 도달 층, 시간, 최종 능력·장비를 볼 수 있습니다.

저장 실패 시 다시 저장 버튼이 표시되며 성공 전에는 메뉴로 나가지 않습니다. 백업에서 복구한 경우 화면에 알립니다. 읽을 수 없는 저장을 새 런으로 교체할 때는 원본을 보존합니다. 이 빌드의 기본 저장 폴더는 `%USERPROFILE%/AppData/LocalLow/DefaultCompany/NHN/RunSaves`입니다.

## 분리된 성장 경로

기본 화력은 노즐 보강 또는 모터 보강을 직접 선택했을 때만 성장합니다. 다른 파워의 총 단계나 층 클리어 자체는 기본 화력을 올리지 않습니다. 각 특수 파워는 설명에 적힌 효과를 적용합니다. 목숨은 런 전체에서 공유하며 보스 처치 시 1개, 최대 3개까지 회복합니다.

특수 파워는 각각 최대 3단계입니다. 노즐 보강과 모터 보강은 각 소유자에 계속 집중 투자할 수 있도록 최대 30단계를 지원합니다. 전부 최대 단계가 되면 정비 보상을 제공합니다.

| 소유자 | 파워 | 전투 변화 |
|---|---|---|
| 플레이어 | 연쇄 살균 | 직접 명중 4회마다 주변 적에게 제한된 추가 피해 |
| 플레이어 | 거품 폭발 | 직접 처치 지점에 아군 잉크와 광역 피해 |

| 플레이어 | 잉크 재활용 | 직접 처치 시 잉크 회수 |
| 플레이어 | 보호 필터 | 주기적으로 피격 1회 차단 |
| 플레이어 | 교대 압력 | 양손 교대 사용 시 일시적 피해 강화 |

| 플레이어 | 노즐 보강 | 플레이어 전용 기본 화력 투자 |
| 플레이어 | 부상 세척 | 잠수 후 부상할 때 주변 정화와 피해 |
| 플레이어 | 역류 세척 | 방어막 파괴 시 주변 피해와 밀어내기 |
| 로봇 | 흡입 모터 | 일반 적을 모음. 보스는 끌어당기지 않음 |
| 로봇 | 회전 브러시 | 로봇 주위 주기적 근접 광역 공격 |

| 로봇 | 회수 보조 | 로봇 직접 처치 시 플레이어 방어막 보조 |

| 로봇 | 모터 보강 | 로봇 전용 공격력·공격 주기 투자 |
| 로봇 | 청소 궤적 | 이동 경로에 충전 가능한 아군 잉크 생성 |
| 로봇 | 탄막 필터 | 근처 적 탄환을 제한된 수만 제거 |
| 로봇 | 예비 탱크 | 가까운 플레이어에게 주기적으로 잉크 공급 |

예를 들어 거품 폭발이 만든 잉크는 살균 촉매와 잠수 충전에 연결됩니다. 로봇의 흡입 모터는 회전 브러시와 살균 분사의 범위 공격을 돕습니다.

로봇 피해는 플레이어의 연쇄·폭발·잉크 회복을 발동하지 않습니다. 추가 피해는 다시 추가 피해나 처치 회복을 발동하지 않습니다. 각 효과에는 별도 대기시간과 대상 수 제한이 있습니다. 보유 효과는 일시정지 화면에서, 플레이어/로봇 누적 피해는 결과 화면에서 확인합니다.

## 무한 모드 기준

- 적 HP: `1 + 0.06 × (층 - 1)`
- 적 피해: `1 + 0.025 × (층 - 1)` — 정수 피해형 적은 마지막에 반올림
- 적 이동 속도: 점진 증가, 최대 약 1.6배
- 보스: 10층 간격, 네 가지 공격 패턴 순환

로봇은 벽으로 가려진 적을 공격하지 않으며, 층 이동이나 거리가 크게 벌어졌을 때 플레이어 주변으로 복귀합니다. 플레이어가 조작 불가능하거나 사망·결과 상태이면 공격하지 않습니다.

## 검증 범위

검증은 Unity 6000.5.6f1의 자동 Play Mode 입력·전환 검사, 실제 피해 처리 검사 및 Windows 빌드 검사로 구성했습니다. 진행 검사에서는 층을 강제로 이동하고 보스를 즉시 처치하며, 입력 검사는 가상 InputSystem 장치와 보호 상태를 사용합니다. 이는 장시간 사람 플레이에 의한 난이도 검증과 다릅니다.

현재 검증은 기능 smoke 범위이며, 이전 총 파워 단계 기반 DPS 비교는 최신 성장 방식에 적용되지 않습니다. 상세 화력 비율, 전체 런 자연 플레이와 난이도 조정은 본격 QA로 남겨 둡니다. 로컬 자동 저장·이어하기·지난 런 기록을 지원합니다. 저장 동작과 검증 범위는 `LOCAL_SAVE_DESIGN.md`를 참고하세요.

새로운 보스별 이동·공격·대응과 20종 파워의 상세 내용은 `BOSSES_AND_POWERS.md`를 참고하세요.


## 후반 전투 밸런스 보정

5층 보스 체력은 유지합니다. 이후 보스에는 `(1 + 0.14 × clamp(층 - 5, 0, 25))²`의 체력 보정을 적용합니다. 이 보정은 30층에서 멈추며, 무한 모드의 기존 층별 체력 배율은 계속 적용됩니다. 보스가 강화 무기에 몇 초 만에 사라져 패턴을 사용하지 못하던 문제를 줄이기 위한 변경입니다.

로봇 기본 공격의 최단 간격은 0.7초입니다. 플레이어와 로봇의 공격력 성장 소유권은 그대로 분리되며, 무투자 로봇의 기본 공격은 1.4초마다 0.35 피해입니다.

실전 자동 검사에서는 실제 무기 입력·탄환 충돌·적 AI·잉크 소모와 잠수 재충전을 사용합니다. 보호 상태의 화력 비교와 무보호 생존 검사는 별도이며, 자동 조작의 처치 시간은 숙련된 사람의 플레이 시간과 다를 수 있습니다. 상세 결과는 `COMBAT_QA_REPORT.md`를 참고하세요.


### 무보호 검사 결과

무보호 자동 조작은 10층 로봇 일반전을 클리어했지만 1층, 20층 보스, 100층 보스 표본에서는 패배했습니다. 사격 없이 이동하는 로봇 집중 20층 보스 표본도 패배했습니다. 방어 특수 파워와 위험 예고를 해석하는 회피를 사용하지 않는 단순 봇 결과이므로, 사람의 진행 불가능을 뜻하지는 않습니다. 다만 무보호 20층 완주와 수동 생존 난이도는 아직 검증 완료로 표시하지 않습니다.

## 로봇 동료 이동과 공격 표시

로봇은 플레이어 주변을 탐색하고 가까운 적에게 접근해 자동 공격합니다. 플레이어와 6 이상 떨어지면 공격을 멈추고 복귀하며, 1.6 안으로 돌아오면 다시 탐색합니다. 이동과 방향 전환은 서서히 바뀌고 장애물을 우회합니다. 층 이동이나 완전히 막힌 경로에서는 안전하게 플레이어 곁으로 복구됩니다.

기본 공격은 노란 발사선과 타격 원으로 보입니다. 주황색 분사, 청록색 연쇄·흡입, 브러시 범위, 초록색 회복 표시가 실제 효과 발생 순간에 나타납니다. Q/E 감속과 Esc 일시정지 중에는 로봇과 효과도 게임 시간에 맞춰 느려지거나 멈춥니다.


## 무기 편성 화면

층 선택 화면에서 현재 양손 무기를 확인하고 무기 편성 열기를 누릅니다. 왼손·오른손의 슬롯은 전투 Q/E 휠과 같은 모양입니다. 슬롯을 클릭해 편집 위치를 고른 다음 오른쪽 무기 목록에서 무기를 클릭하세요. 슬롯을 클릭하기만 해서는 장비가 바뀌지 않습니다.

편성 적용 · 돌아가기로 확정하고 출발하면 화면의 편성을 사용합니다. 취소 · 돌아가기 또는 Esc는 변경을 버립니다. 기존 편성으로 바로 출발해도 됩니다. 무기별 아이콘은 편성 화면과 전투 휠에서 동일하게 표시됩니다.

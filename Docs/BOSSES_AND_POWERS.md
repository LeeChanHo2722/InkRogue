# 보스별 전투 방식과 파워 20종

2026-10-07. `40783d9` 이후 별도 기능 단위. 기존 아트와 무기, 룸, 20층/무한 모드 구조를 유지한다.

## 보스

| 보스 | 공격과 이동 | 대응 |
|---|---|---|
| 오수 저장체 | 천천히 접근하며 플레이어의 당시 위치에 시간차 오염 구역을 남긴다. | 경고를 한쪽으로 유도한 뒤 되돌아가지 않고 깨끗한 경로로 이동한다. |
| 환풍구 군주 | 좌우 측면으로 이동하고 조준을 고정한 뒤 부채꼴 연사를 한다. | 조준이 고정된 후 부채꼴 밖으로 횡이동한다. |
| 폐기물 압축기 | 가로 또는 세로 방향을 고정해 긴 구역을 예고하고 돌진한다. 돌진 후 멈춰 회복한다. | 긴 경고선 옆으로 빠져나온 뒤 회복 시간에 반격한다. |
| 타워 오염핵 | 중앙을 유지하며 녹색 안전 방향을 남긴 방사형 탄막과 방향이 바뀌는 십자 위험 구역을 교대한다. | 초록 부채꼴의 틈과 십자 사이 공간을 오간다. |

일반 위험 구역은 노란색 외곽선으로 예고하고 발동 때 흰색으로 표시한다. 구역 판정은 표시한 캡슐과 일치하며 한 번만 피해를 준다. 보스 정지·사망·페이즈 전환은 남은 구역을 즉시 비활성화한다. 돌진 및 이동은 현재 아레나 타일과 장애물을 검사한다. 기존 체력 페이즈 전환 연출과 소환 흐름은 유지한다. 대응 방법은 보스 등장 화면에 표시한다.

## 신규 파워

기존 ID를 보존하고 5개를 뒤에 추가해 총 20개다. 모두 기존 수동 보상 선택과 최대 단계 제외 규칙을 이용한다.

| 소유자 | 파워 | 기능 |
|---|---|---|
| 플레이어 | 부상 세척 | 0.6초 이상 잠수 후 부상하면 주변을 아군 잉크로 정화하고 범위 피해. 재발동 4초. |
| 플레이어 | 역류 세척 | 방어막이 실제 파괴되면 주변 일반 적을 밀고 피해. 보스는 밀지 않는다. 재발동 8초. |
| 로봇 | 청소 궤적 | 움직이면서 일정 간격으로 아군 잉크를 남겨 잠수·충전 경로를 만든다. |
| 로봇 | 탄막 필터 | 가까운 시야 내 적 탄환을 단계당 한 개씩, 최대 세 개 제거한다. 폭탄·바닥 경고·아군 탄환은 대상이 아니다. 재발동 5초. |
| 로봇 | 예비 탱크 | 플레이어 가까이에서 6초마다 잉크를 전달한다. |

부상 세척·역류 세척은 PlayerPower 피해로 기록되며 직접 명중/처치 효과를 다시 발동하지 않는다. 로봇 지원 파워는 다른 소유자의 기본 공격력을 올리지 않는다. 파워 총 단계 자동 기본 화력 증가는 계속 제거된 상태다.

## 검증 범위

`TowerVarietyValidation.Start`는 20개 ID 중복, 신규 효과·쿨다운·소유자·재귀 방지, 최대 단계 제외, 수동 보상 중복 방지, 4종 보스의 경고·이동·사격·정지 시 취소를 짧은 Play Mode 검사로 확인한다. 파워는 제어된 타깃/직접 호출도 사용한다. 보스는 실제 전투 코루틴의 한 사이클씩 실행하며 장시간 난이도 시뮬레이션은 하지 않는다.

`TowerPlayValidation.Start`, `TowerPowerValidation.Start`로 기존 진행 및 파워 효과 회귀를 확인한다. 확인 로그와 Windows 빌드 식별자는 작업 루트의 최신 delivery 문서에 기록한다.

## 남은 작업

전체 런 자연 플레이, 모든 체력 페이즈의 패턴 조합, 움직이는 보스의 맵별 경계 상황, 예고 가독성의 사용자 플레이 확인, 90초 페이스와 플레이어·로봇 100:60 목표의 수치 QA는 별도다. 정식 그래픽·음원 제작, 추가 서비스와 Steam 배포는 포함하지 않는다.

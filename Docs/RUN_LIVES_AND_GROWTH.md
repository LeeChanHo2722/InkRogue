# 런 공통 목숨과 직접 선택 성장

2026-10-07. Floor UX 변경 다음의 별도 기능 단위.

## 구현

- BootstrapScene의 PlayerLifeManager가 런 동안 목숨을 유지한다. 일반 층 이동은 사망 연출 상태만 정리하며 목숨을 복구하지 않는다.
- 새 런 시작과 재시작에서 초기 목숨을 복구한다. 현재 설정은 3개다.
- 보스 처치 보상은 해당 층당 한 번만 목숨 1개를 회복한다. 최대 3개이며, 이미 목숨이 0인 런을 부활시키지 않는다.
- 방어전의 기존 규칙은 유지한다. 플레이어 사망은 방어 목표의 목숨을 소비하지 않으며, 방어 목표 파괴가 공통 목숨을 소비한다.
- 파워 수동 선택은 유지한다. 파워 총 단계에 따른 자동 기본 화력 성장을 없앴다. 플레이어 기본 공격력은 **노즐 보강** 단계, 로봇 기본 공격력과 공격 주기는 **모터 보강** 단계만 읽는다.
- 연쇄·회복·방어·잉크 효과 등은 선택한 효과만 적용한다. 로봇의 기본 공격과 보조 공격 모두 같은 모터 단계 기준을 사용한다.
- 기존 노즐/모터 성장 수식과 각 파워 효과 수치는 유지했다. 정밀한 화력 비율이나 난이도를 맞췄다는 의미는 아니다.

## 간단 검증

`TowerPlayValidation.Start`에서 26개 검사를 통과했다. 실제 방어막 피격과 사망 이벤트·부활, 다음 맵 진입과 목숨 유지, 보스 회복 및 중복 콜백, 20층 승리, 무한 모드 계속 진행, 마지막 목숨 소진과 재시작을 확인했다. 전투 클리어와 보스 처치는 테스트용 제어를 사용했으며 자연 플레이의 난이도 검증은 아니다.

`TowerPowerValidation.Start`에서 28개 검사를 통과했다. 파워 효과와 소유자 분리, 무기 교체 시 적용, 로봇 공격과 재시작을 확인했다. 과거의 파워 총 단계 기반 DPS 가정과 240 HP 처치 시간 강제 검사는 제거했다.

Unity 6000.5의 알려진 SearchDatabase 초기화 예외는 임시 테스트 도우미가 별도로 기록하고 Editor 일시정지를 해제한다. 게임 예외를 제외하지 않는다. 도우미는 제품 소스와 최종 빌드에서 제거한다.

## 본격 QA에 남기는 사항

- 일반 층 약 90초의 권장 페이스와 난이도. 강제 제한 시간은 아니다.
- 동일 투자에서 플레이어 100 : 로봇 약 60의 실제 화력 목표, 반대 소유자 비투자 화력, 빌드별 효율.
- 장시간 보스/웨이브/생존 전투, 전체 런 자연 플레이, 대규모 seed 재검증.
- 보스별 추가 고유 패턴과 정식 아트·사운드 제작. 이번 변경에 포함하지 않았다.
- Steam 출시는 별도 범위이며 게시하거나 배포하지 않았다.

사용자 지시에 따라 위 수치 검증은 이번 기능 완성과 빌드의 통과 조건으로 두지 않는다.
